L1 Watcher

The L1 Watcher is a shared TypeScript component. It runs inside one network stack, publishes normalized L1 facts, and delegates chain-specific work to the adapter for that network.

The Milestone 1 adapter is Zeko-M / Mina. The Milestone 4 adapter is Zeko-E / Ethereum. Each adapter owns its chain data model, finality model, and historical recovery guarantees.

1 watcher package shared lifecycle, health, NATS, cursors, rollback publication
2 adapter families Zeko-M / Mina now, Zeko-E / Ethereum later
1 hard blocker Archive-Node-API zkappCommands for rebuildable Mina bridge history
Component Boundary

Shared Watcher, Provider Adapters

The shared watcher owns lifecycle, health, durable cursors, NATS publication, and rollback fact publication. Adapters own Mina daemon semantics, Archive-Node-API behavior, Ethereum log shape, and finality policy.

Shared

L1 Watcher

  • Owns process lifecycle, health, NATS publication, durable state, and retries.
  • Publishes shared settlement, rollback, bridge, and health facts.
  • Stores provider-neutral block hashes and published fact IDs for rollback events.
Milestone 1

Zeko-M / Mina Adapter

  • Uses Mina daemon GraphQL and Archive-Node-API.
  • Publishes Mina outer actions from OUTER_PK.
  • Needs upstream zkappCommands for rebuildable bridge history.
Milestone 4

Zeko-E / Ethereum Adapter

  • Uses Ethereum JSON-RPC plus an archive/log source.
  • Requires contract addresses, ABIs, archive guarantees, and finality policy.
  • Defines whether any Ethereum equivalent to outer actions exists.
Zeko-M / Mina Finding

Historical Bridge Recovery Is Blocked Without Archive-Node-API Work

Archive-Node-API can rebuild Zeko-M outer actions and settlement commits through actions(OUTER_PK). It cannot currently rebuild all bridge events because deposits and cancels require account update actions, events, app state, and preconditions.

Milestone 1 requirement: add an Archive-Node-API zkappCommands(input) query that returns successful Mina zkApp commands by block range with full account update details.
Recoverable today
Outer actions and settlement commits from actions(OUTER_PK).
Not recoverable today
Historical deposit submissions and cancels after daemon frontier/NATS retention is gone.
UI/API impact
Return partial records with data-quality warnings, not blocked pages.
Implementation detail
Use deterministic IDs and cursor advancement after JetStream ack plus durable write.
Gap Behavior

If the upstream query is missing

  • Bridge events become live-only from daemon frontier and retained NATS.
  • Watcher downtime can create an unfillable Zeko-M bridge gap.
  • Cancel history is weakest because cancels emit no outer witness action.
